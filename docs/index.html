A tabbed terminal
that keeps exited tabs alive.

AgenTerm is a native Windows cmd.exe terminal with persistent tabs, a tab tree, a scriptable control plane, and a tmux-style compatibility client — built to be driven by both humans and agents.

Features

A small, deliberate surface: everything is reachable from the GUI and the CLI.

▣Persistent tabs

Exited shells stay open as readable, scrollable snapshots. Close is always explicit — output is never lost to a process exit.

├Tab tree

Tabs form a hierarchy. Closing a parent promotes its children instead of killing them; parent cycles are rejected.

>_Control CLI

agenterm-cli drives windows, tabs, keys, capture and workspaces over a bounded loopback IPC with typed receipts.

⚙tmux compatibility

agenterm-mux maps a documented tmux/RMUX subset onto AgenTerm. Unsupported commands fail explicitly, never silently.

{ }Rhai scripting

One-invocation constrained Rhai workers call a versioned script API with budgets, audit records, and typed failures.

◔Themes & snapshots

Built-in light/dark palettes, PNG capture, and structured UI snapshots for rendering verification and automation.

Scriptable by design

Discover the live interface instead of reading a manual.

$ agenterm-cli list-commands
$ agenterm-cli protocol-info
$ agenterm-cli ui-snapshot # structured state for agents
$ agenterm-cli wait-pane -t @1 --text "BUILD SUCCEEDED" # no fixed sleeps
