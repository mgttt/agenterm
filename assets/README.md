# AgenTerm icon assets

- `agenterm-icon.png`: transparent high-resolution source used for review.
- `agenterm.ico`: Windows multi-size icon embedded by `build.rs`.
- `agenterm.icns`: macOS multi-size application icon installed in the app bundle.

The mark was generated with the built-in image-generation tool, then converted
from a flat magenta chroma-key background to transparency and packed at
16/20/24/32/40/48/64/128/256 px.

Final prompt:

> Create a bold, minimal Windows developer-tool icon combining a terminal
> prompt chevron with two stacked terminal panes. Use a rounded dark navy tile,
> electric cyan and warm amber accents, a crisp flat vector-like silhouette,
> generous padding, no text, and enough clarity for 16 px. Avoid resemblance to
> PowerShell, Windows Terminal, VS Code, Docker, or other existing brands.
